What we do

Data platforms on Azure Databricks
We design and build lakehouse platforms with Azure Databricks, Azure Data Factory, ADLS Gen2, Delta Lake and Unity Catalog. Every table sits in a bronze, silver or gold layer with a clear owner and a clear purpose.

Delivered an enterprise lakehouse for a NSW council, bringing seven source systems into one governed platform.

Moving reports off spreadsheets and legacy SQL
Many reports still depend on SharePoint files and hand-maintained queries. We move them onto governed tables and re-point your Power BI models, and we check the numbers match before anyone switches over.

Retired legacy extraction jobs, moved a SharePoint pipeline from deprecated authentication to Entra ID and Microsoft Graph, and reconciled new tables against the manual reports they replaced.

KPI and operational reporting
Workforce, service delivery and project portfolio reporting, built with the people who own each KPI and explained in plain language so they can check the result themselves.

Delivered 36 workforce metrics from 18 conformed reporting tables, with monthly snapshots that show how each KPI changes over time.

Private AI on hardware you own
We set up language models that run inside your premises, so documents and client records never leave your control. We build and test each setup on our own equipment before we recommend it.

In a council setting, our principal also built AI-assisted tooling that writes technical documentation and a data dictionary from catalog metadata and lineage.

How an engagement runs

  1. Agree the questions

    We start with the decisions your reports must support and who owns each number, before any code is written.

  2. Ingest from your sources

    We connect to your systems, APIs, files and databases and load their data on a schedule. It is stored in open, industry-standard formats on Azure storage, and every load is logged, so you can always trace a figure back to what arrived.

  3. Transform and model

    Silver tables fix dates, duplicates and names, and we check them against the source and any existing reports. Gold tables hold the figures you report, modelled for your reporting tool, with history kept where you need to see change over time. Every business rule is written down, so anyone can see how a figure is produced.

  4. Hand over

    You get documentation, a monitored schedule and a walkthrough, so your team can run it without us.
